Vision Wire
Send Receive QR Generator

Move files through light, not wires.

Vision Wire streams a file as a dense, animated binary grid on one screen and reconstructs it from a camera pointed at that screen on another device — no network, no cable, no pairing. A custom grid format (denser than QR), adjustable transfer speed, automatic camera-FPS matching, and a rateless fountain code for lost-frame recovery make it faster and more resilient than swiping through a stack of QR codes.

Denser than QR

A lightweight 22-byte header + CRC32 replaces QR's finder patterns and baked-in Reed–Solomon overhead, so a custom grid carries meaningfully more payload per cell — and the grid size auto-scales (48–128 px) to the file and camera quality.

Camera-aware speed

The receiver measures the camera's actually delivered frame rate (not just what the driver claims) and the sender's speed slider is matched against it, so you're never paying for frames the camera can't keep up with.

Three recovery modes

None (max speed, ideal conditions), XOR block-parity (cheap single-loss recovery), or a rateless LT fountain code that reconstructs the whole file from any sufficiently large set of symbols — immune to which frames were actually missed.

Off-thread decoding

All per-frame grid sampling and error correction runs in a Web Worker, so the camera capture loop and UI stay smooth even at high grid resolution and frame rate.
